Access Management

All-In-One Access Rights Manager - Hide Fields, Menus, Buttons, Chatter, Filters, Import/Export

10 Powerful Feature Categories

Model Access

Hide Archive, Unarchive, Delete, Duplicate, Create, Edit, Import, Export, Properties per model and per security group.

Field Access

Make any field Invisible, Read-Only, or Required per model per group. Remove external links on Many2one fields.

Menu Access

Hide any menu or submenu per user group. Users won't see menus they shouldn't access — server-side enforced.

Button/Tab Access

Hide specific buttons (action_confirm, button_validate, etc.) or notebook tabs (Other Info, Notes) per model per group.

Chatter Access

Hide Send Message, Log Note, Activities, Followers, Scheduled Messages per model. Or hide entire chatter globally.

Filter Access

Hide specific search filters and group-by options per model. Control what data views users can create.

Import/Export Control

Disable Import and/or Export per model or globally. Prevent data extraction by unauthorized users.

Disable Debug Mode

Block developer/debug mode for specific user groups. Prevent users from accessing technical menus.

Read-Only User

Make entire users read-only across ALL models. They can view everything but can't create, edit, or delete anything.

Restrict Reports/Actions

Hide specific server actions and print reports from the action menu. Users only see reports they need.

Domain Restrictions

Conditionally restrict Create/Edit/Delete based on record field values. E.g. locked records become read-only.

Multi-Company

Every rule can be scoped per company or applied globally. Perfect for multi-company environments.

Simple 3-Step Setup

Choose Rule Type

Model Access, Field Access, Menu, Button, Chatter, Filter, or Global.

Configure

Pick the model, field, menu, or button. Toggle what to hide. Set target groups.

Done!

Rules take effect immediately. No server restart needed. No code required.
